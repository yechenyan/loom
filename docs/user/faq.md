# FAQ

## Is `loom scan` a shell command?

No. `loom scan ...` is the chat form. The terminal command is `loomcli scan-index ...`.

## Does `loomcli ask` exist?

No. Questions belong to the agent workflow: inspect `loom/` first, then fetch exact raw files.

## Should I always put data under `raw_data/`?

No. That is the default convention, but Loom can scan other local source directories too.
